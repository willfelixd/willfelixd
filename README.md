### 🎤 Artist Showcase — *Em finalização*

API REST + Frontend para o portfólio digital da cantora **Isa Tavares**.  
Agenda de shows, repertório, vídeos e contato com painel admin protegido por JWT.

<details>
<summary>📋 Ver detalhes</summary>

<br/>

**Stack:** Java 17 · Spring Boot 3 · Spring Security · JWT · PostgreSQL · Redis · Docker · React 18 · TypeScript · Vite

**Destaques técnicos:**
- Autenticação stateless com Spring Security + JWT
- Cache estratégico com Redis e invalidação por escrita
- Rate limiting no endpoint de contato (3 req/hora por IP)
- Integração automática com YouTube (thumbnail e embed via URL)
- Validação de conflito de horário nos agendamentos
- CI/CD com GitHub Actions e deploy automático no Render

**Status:**
- ✅ Backend — concluído e em produção no Render
- 🚧 Frontend — em desenvolvimento (React 18 + TypeScript + Vite)

</details>
