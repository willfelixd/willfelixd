REST API + Frontend for the digital portfolio of singer **Isa Tavares**.  
Show schedule, repertoire, videos and contact with JWT-protected admin panel.

<details>
<summary>📋 See details</summary>

<br/>

**Stack:** Java 17 · Spring Boot 3 · Spring Security · JWT · PostgreSQL · Redis · Docker · React 18 · TypeScript · Vite

**Technical highlights:**
- Stateless authentication with Spring Security + JWT
- Strategic cache with Redis and write invalidation
- Rate limiting on contact endpoint (3 req/hour per IP)
- Automatic YouTube integration (thumbnail and embed via URL)
- Booking time conflict validation
- CI/CD with GitHub Actions and automatic deploy on Render
